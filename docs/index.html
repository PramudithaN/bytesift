01 Binary Inspection

Binary Magic Signature Sniffing

When a user renames a file or an application saves without an extension, conventional tools fail. ByteSift opens files in raw binary mode and reads only the initial 16 to 64 bytes.

Matched Signatures:
PDF: %PDF- (0x25 0x50 0x44 0x46)
JPEG: \xFF\xD8\xFF
ZIP/DOCX: PK\x03\x04
02 Text Heuristics

Bounded Heuristic Text Scoring

For plain text, source code, and documents, ByteSift evaluates a bounded 4 to 8 KB window with weighted keywords and regular expressions.

Deterministic Categories:
• Invoices: "Total Due", "Invoice #", "IBAN", "VAT"
• Resumes: "Experience", "Education", "Skills"
• Code: "def ", "class ", "import ", "SELECT "
03 Safe Routing

Deduplication & Zero-Overwrite Defense

Files are checked for identical duplicates using a two-pass size check and chunked SHA-256 hashing. Duplicates are cleanly isolated into a dedicated folder.

Collision Guarantee:
If destination has report.pdf, incoming becomes report (1).pdf. No data is ever overwritten.
04 Atomic Journal

Atomic Execution & Instant Undo

Every single file movement is written to a local atomic journal file (.bytesift_history.json).

1-Key Instant Reversibility:
Hit ⌘Z on macOS or Ctrl+Z on Windows to roll back every file to its exact original location.
Zero-Dependency Architecture

High-Throughput Pipeline

Every subsystem is built purely with standard libraries for maximum security, zero vulnerability, and instant boot times.

01 / MAGIC ENGINE

Direct Binary Signatures

Inspects raw byte arrays without executing or loading large containers into RAM. Recognizes PDF, PNG, JPEG, HEIC, MP4, MKV, ZIP, TAR, GZ, and Executables in under 1 millisecond.

Path: bytesift.inspectors.magic_bytes
02 / HEURISTICS

Bounded Keyword Scoring

Safe 4-8 KB read limit eliminates memory exhaustion on massive log files or database dumps. Deterministic scoring algorithms reliably segregate invoices, resumes, contracts, and code.

Path: bytesift.inspectors.text_heuristics
03 / DEDUPLICATOR

Chunked SHA-256 Hasher

First clusters files by byte size. Only files with matching sizes undergo chunked SHA-256 hashing (64 KB chunks). Fast, memory-conservative duplicate isolation.

Path: bytesift.inspectors.hasher
04 / TRANSACTION

Atomic Undo History

Every operation writes an append-only JSON journal to the target directory. Undo reverses every relocation while preserving timestamps and restoring initial directories.

Path: bytesift.core.transaction
