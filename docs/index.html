The Inspection Engine

Why file extensions lie, and how ByteSift reads the truth

Windows File Explorer and macOS Finder rely on the letters after the dot. If an archive or executable is renamed to invoice.pdf, the OS is fooled. ByteSift reads the binary headers directly without executing a single byte.

Ordinary File Managers Extension Only

Trusting the suffix leads to misclassification

When software organizes by file extension alone, mismatched files end up in the wrong directories. Worse, disguised files sit in documents folders pretending to be benign documents.

Filename on Disk:
Annual_Report.pdf
Operating System assumes: Adobe PDF Document
Result: A renamed ZIP archive or script gets filed into Documents, cluttering your workplace.
ByteSift Inspector <2ms Binary Sniff

Inspecting binary signatures reveals the actual format

ByteSift opens files in strict read-only binary mode, reads the first 16 bytes, and cross-references them against standard format specifications. Zero code execution, zero security risk.

First 4 Bytes at Offset 0x00:
50 4B 03 04 Decoded: PK.. (ZIP Container)
ByteSift identifies: Archives/ZIP Container
Result: 100% accurate classification. Code, media, and archives sort into proper destinations every time.

Zero-Loss Architecture

The 4-stage local safety pipeline

How ByteSift protects your files from accidental loss, collisions, or crashes during every single sort.

01
Cryptographic

Streamed SHA-256

ByteSift reads files in 64 KB streaming chunks so large videos never exhaust RAM. It matches identical duplicates byte-for-byte, even if names differ completely.

02
Inspection

Binary Sniffing

Checks magic headers for 40+ media/archive formats, followed by UTF-8 syntax heuristics for Python, TOML, Markdown, and YAML without executing scripts.

03
Zero Overwrites

Collision Guard

If a destination file already exists (e.g. invoice.pdf), ByteSift automatically appends an incremented suffix like invoice (1).pdf. No file is ever crushed or replaced.

04
Atomic Journal

1-Click Undo Log

Every movement records its exact source and destination into a local transaction journal. Press Ctrl+Z or click Undo, and the entire move sequence reverses instantly.

Frequently Asked Questions

Safety, privacy and trust

ByteSift was engineered so you never have to worry about lost files, telemetry, or hidden surprises.

Does ByteSift delete anything?

Never. ByteSift does not delete, alter, or overwrite files. It only organizes files into clean subfolders within the directory you explicitly choose.

Before any file moves, you can preview the complete plan. If a filename collision occurs, ByteSift automatically appends an incremented suffix (e.g. file (1).pdf) rather than replacing existing files.

What happens to duplicates?

ByteSift calculates cryptographic SHA-256 hashes to identify identical copies (exact same content), even if they have different filenames.

Rather than deleting duplicate copies, ByteSift safely isolates them into a dedicated Duplicates/ folder. You can review them with peace of mind or delete them whenever you choose.

How do I undo an organization session?

Simply press Ctrl+Z (or Cmd+Z on macOS) or click the Undo Last Session button.

ByteSift writes an atomic session transaction log, allowing every single moved file to be restored to its exact original location in milliseconds.

Why did Windows or Edge show "isn't commonly downloaded"?

ByteSift is a 100% free, community-driven open source tool. Extended Validation (EV) code-signing certificates from corporate authorities cost upwards of $500 per year. When any newly compiled open-source executable is downloaded, Microsoft SmartScreen and browsers display a standard "isn't commonly downloaded" reputation notice until tens of thousands of downloads have occurred.

To run the installer: in Edge/Chrome click ... → Keep → Keep anyway. In Windows SmartScreen, click More info → Run anyway. You can verify every single line of Python code on our public GitHub repository.

Does it require an internet connection or send telemetry?

Zero network activity. ByteSift runs 100% offline on your device. It requires no user account, transmits zero telemetry, and never makes external server calls. Your files and metadata never leave your computer.
