Questions & answers

Everything you need to know about safety and privacy.

Does ByteSift delete anything?
Never. ByteSift does not delete, alter, or overwrite files. It only organizes files into clean subfolders within the folder you choose.
What happens to duplicates?
ByteSift identifies identical copies using cryptographic SHA-256 hashes and isolates them into a dedicated Duplicates folder. You can review them safely anytime.
How do I undo an organization?
Press Ctrl+Z (or Command-Z on macOS) or click Undo Last Session. ByteSift keeps an atomic local journal that restores every file to its previous location.
Why did Windows or Edge show "isn't commonly downloaded"?
ByteSift is a free community open-source tool without expensive commercial certificates. When newly compiled, Windows displays a standard reputation warning until thousands have downloaded it. Click More info → Run anyway. All code is public on GitHub.
