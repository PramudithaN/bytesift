Workflow Pipeline

How ByteSift inspects your files.

Deterministic, multi-tiered content examination operating 100% locally on your computer.

01

Binary Magic Signature Sniffing

ByteSift reads the first 16 to 64 bytes of the binary header directly from disk. Even if a file is missing its extension or was renamed from .dat, its immutable signature (e.g. %PDF-, \xFF\xD8\xFF, PK\x03\x04) accurately determines whether it is an Image, Document, Video, or Archive.

02

Bounded Text & Keyword Heuristics

For plain text, code, and documents, ByteSift scans a bounded 4 to 8 KB sample against deterministic keyword and regex rules. Invoices, receipts, resumes, software code (Python, JS, HTML, SQL), and server logs are cleanly identified without language models or cloud APIs.

03

Collision-Proof Safe Relocation

Files are never overwritten. When multiple files share the same filename in a destination directory, ByteSift automatically suffixes collisions with filename (1).ext. Exact duplicates are isolated into a dedicated Duplicates/ folder via size-grouped SHA-256 hashing.

04

Session Journal & 1-Click Rollback

Every file movement is recorded in a transactional history manifest (.bytesift_history.json). If you ever change your mind or need to restore your directory layout, a single click or running bytesift undo restores every file to its exact origin and prunes empty folders.
